Summary of key /proc/net/* files:

File	Meaning
route	Kernel IPv4 routing table
ipv6_route	Kernel IPv6 routing table
dev	Interface stats (like /sys/class/net/*)
if_inet6	IPv6 addresses assigned to interfaces

udp, udp6	Open UDP sockets
netlink	Netlink socket table
wireless	Wireless interface stats
